# Openhash-Gopang / Passport

**혼디(Hondi) 오픈해시 기반 디지털 여권 프로젝트**

## 한 줄 요약

각국이 이미 채택 중인 국제 신원 표준(ICAO DTC, ISO/IEC 18013-5 mDL, eIDAS 2.0)의
**참조 구현체(reference implementation)**로서 혼디 지갑을 제공하고, 오픈해시 분산원장은
신원정보 자체가 아니라 **폐기/신뢰목록 변경 이력의 위변조 불가능한 감사 로그**로만 기여한다.

국가의 발급 권한을 대체하지 않는다. 국가 시스템 위에 얹히는 감사·투명성 레이어다.

## 핵심 원칙 (혼디 기존 원칙 승계)

- **"서버는 평문을 못 읽는다"**: 신원정보 원본은 각국 로컬 시스템 + 사용자 기기에만 존재
- **절차가 기관보다 먼저**: 국가별 발급 절차 차이를 흡수하는 것은 혼디 지갑, 오픈해시는 결과(해시)만 앵커링
- **감사 로그 ≠ 신원 데이터베이스**: 오픈해시 노드는 신원정보 대신 폐기·서명키 교체 이력의 해시만 기록

## 3단계 로드맵

1. **Phase 0 — 국내 신뢰 구축**: 제주 → 전국 디지털 신분증/이동수단 (기존 Gopang 인프라 확장)
2. **Phase 1 — 국제표준 정합**: ICAO DTC / ISO 18013-5 / eIDAS 2.0 참조 구현체화
3. **Phase 2 — 감사·투명성 레이어**: 오픈해시를 국가 PKI 루트 대체가 아닌 폐기·신뢰목록 이력 앵커링 레이어로 통합

자세한 내용은 [ROADMAP.md](./ROADMAP.md) 참고.

## 관련 저장소

- `gopang` — 제주도청 AI 어시스턴트 (Phase 0의 기반 인프라)
- `gdc` — GDC 과금/지갑 인프라 (device-link 인증 흐름 재사용 대상)
- `users` — 사용자 GUID/PDV 관리

## 비범위 (Non-goals)

- 국가 발급 권한을 오픈해시가 대체하는 것 (정치적으로 불가능하며 시도하지 않음)
- 생체정보 원본을 국경 간 전송하는 것 (ZK 증명으로만 대체)
- 물리 여권의 즉각적 폐지 (병행 사용 전제)
